# Bloxkeep's name and logo

Bloxkeep's code is [MIT](LICENSE): you're welcome to copy it, change it and share it. One request about the name and
the logo, so people can always tell the real Bloxkeep from a copy (fake downloads with harmful code added are common in
the Roblox world):

- **Made your own version?** If you added, removed or changed features, please give it its own name and logo, not
  Bloxkeep or something close to it. Saying "based on Bloxkeep", with a link here, is great.
- **Just building this repository as it is?** Keeping the name and logo is fine.
- **Writing about Bloxkeep, reviewing it, making videos?** Go ahead, name and logo included.

Please don't make a copy look like the official Bloxkeep. The official one is released only at
https://github.com/Bloxkeep/roblox-account-manager and https://bloxkeep.github.io/roblox-account-manager.

Not sure? Just ask in an issue: https://github.com/Bloxkeep/roblox-account-manager/issues
